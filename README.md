# POP! TETRIS

A pop-art Tetris game with an original folk chiptune soundtrack, built as a single self-contained HTML file.

**Play:** https://margmarg.github.io/pop-tetris-oct-21/

## Controls

- `←` `→` move
- `↑` / `X` rotate clockwise
- `Z` rotate counter-clockwise
- `↓` soft drop
- `Space` hard drop
- `C` hold
- `P` pause
- `R` restart
- `M` mute

Touch controls appear automatically on phones.

## Notes

- No libraries, images or audio files. The soundtrack is synthesized live with the Web Audio API.
- Best score is stored in your browser's local storage.
